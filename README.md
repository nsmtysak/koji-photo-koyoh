# 作業報告書

iPhone に保存済みの「黒板が焼き込まれた工事写真」を選び、並べ替え・施工区分の付与をして、
**写真3枚/ページの作業報告書PDF**を生成し、メールで送付するための PWA アプリです。

公開URL: https://nsmtysak.github.io/koji-photo-koyoh/

## 使い方（基本の流れ）

1. **工事情報**を入力（注文番号 / 工事名 / 工事場所）
2. **写真を選択／追加**（カメラロールから複数選択。黒板は焼き込み済み前提で無加工）
3. **並べ替え**（▲▼）・不要な写真は ✕ で削除（この順がPDF掲載順）
4. 各写真に**施工区分**を付与（候補チップ選択／自由入力。候補はその場で追加・削除可）
5. **PDFを生成** → プレビュー / 保存 / メールで送付
6. 別の工事を始めるときは **「最初からやり直す（クリア）」**

## 設定（右上「設定」）

- **自社情報**（表紙下部に表示）
- **メール雛形**（送信宛先 / 件名。件名は `{工事名}` を差し込み可）
- **施工区分タグ**の管理

設定・工事情報は localStorage に保存されます。**写真と写真ごとの区分はセッション中のみ**保持し、永続化しません。

## PDF について

- pdf-lib + fontkit を**ローカル同梱**（オフラインでも生成可）。
- 日本語フォントは **M PLUS 1p（TrueType）を全グリフ埋め込み**。
  - pdf-lib のサブセット機能はグリフ欠落の不具合があり、CFF（OpenType）フォントは
    埋め込みが壊れて iPhone で文字化けするため、TrueType＋全埋め込みにしています
    （その分フォント約1MBがPDFに含まれます）。
- 表紙（作業報告書 / 発行日 / 注文番号・工事名・工事場所 / 自社情報）＋ 写真3枚/ページ（右に施工区分）。
- ファイル名: `作業報告書_{工事名}_{日付}.pdf`

## メール送付の挙動と制約（重要）

ブラウザからのメール自動送信はできません。PDF生成後に **宛先を画面で入力／選択**（設定の宛先が初期値・毎回編集可・過去の宛先は候補から選択）した上で、用途に応じて2つの方法を用意しています。

- **「PDFを送る」**（Web Share API / 共有シート）
  - iPhone: 共有シートが開き、**メールを選ぶとPDFが自動添付**され、**本文に定型句**が入ります。
  - タップ時に**件名を自動でクリップボードにコピー**します。メールの**件名欄を長押し→ペースト**で貼り付け。
  - **宛先はメールアプリ側で入力**します（毎回入力。iOSの仕様で宛先・件名は自動入力できないため）。
  - PC等（共有シート非対応）: PDFをダウンロード保存します（メールに手動添付）。
- **件名**は設定の雛形（`{工事名}`差し込み済み）。**本文**は設定の定型句（複数登録・選択式）。

> iOSでは「PDF添付」と「宛先・件名の自動入力」を同時に行う方法がありません。本アプリは
> **添付と本文定型句を自動化**し、件名は自動コピーして貼り付け、宛先はメールアプリで入力する方式です。

> iOS の制約上、「宛先 ＋ 件名 ＋ 添付」を1アクションで完全自動化することはできません。
> そのため「宛先・件名つきでメール作成（添付は手動）」と「PDFを添付で共有／保存」の2方式を用意しています。
> 宛先は毎回変わる前提で、PDF生成後の画面で入力・選択できます（直近に使った宛先は候補表示）。

## 技術

- バニラ HTML / CSS / JavaScript（ビルドツール・フレームワーク不使用）
- PWA（manifest + Service Worker。SWは network-first で更新が反映されやすい）
- 外部ライブラリは PDF生成用（pdf-lib + fontkit）のみ

詳細な構成・方針は [CLAUDE.md](CLAUDE.md) を参照。
